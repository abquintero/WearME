# WearMe

WearME is a university engineering project focused on developing a non-invasive wearable device for monitoring physiological parameters associated with respiratory health.

The system integrates embedded hardware, biomedical sensors, wireless communication, and a mobile application to measure and display key physiological variables, including respiratory rate, heart rate, and peripheral oxygen saturation (SpO₂).

An accelerometer MPU6050 is used to detect thoracic movement and estimate respiratory rate, while a MAX30102 optical sensor measures heart rate and blood oxygen saturation. The device communicates with an Android application through Bluetooth Low Energy (BLE), where measurements are displayed through real-time graphs and threshold-based alerts.

## Key features:
- Non-invasive monitoring of respiratory rate through thoracic movement.
- Heart rate and SpO₂ measurement using an optical sensor.
- Embedded system development and sensor integration.
- Wireless data transmission using Bluetooth Low Energy (BLE).
- Android application for physiological data visualization.
- Threshold-based alerts to identify measurements outside predefined ranges.

**Technologies:** Embedded Systems, STM32, MAX30102, Accelerometer, Bluetooth Low Energy (BLE), Flutter, Dart, Android.
